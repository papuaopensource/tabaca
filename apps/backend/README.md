# tabaca-backend

Backend untuk [Tabaca](https://github.com/papuaopensource/tabaca) — ekstensi browser yang mengumpulkan cerita-cerita dari Papua, One Tab Away.

Project ini menyediakan API yang digunakan oleh ekstensi untuk mengambil cerita, serta panel admin untuk mengelola sumber berita dan kata kunci kurasi Papua.


## Sumber berita

Tabaca mengumpulkan cerita dari empat sumber:

| Sumber | Fokus |
|---|---|
| BBC News | Liputan Papua internasional (Asia) |
| The Conversation | Analisis akademis Papua & Pasifik |
| Jubi | Media lokal Papua independen |
| Antara Papua | Kantor berita nasional, desk Papua |

Cerita difilter otomatis berdasarkan kata kunci yang berkaitan dengan Papua — mulai dari nama wilayah, suku, hingga isu-isu yang relevan.
